# 🔐 Spring Boot Session Security

A simple learning project demonstrating **session-based authentication** using Spring Security.

## 📖 About

This project was built to understand how Spring Security handles user authentication using HTTP sessions. After a successful login, the server creates a session and authenticates subsequent requests using the session cookie.

## ✨ Features

- User Registration
- User Login
- Session-Based Authentication
- Password Encryption with BCrypt

## 🛠️ Tech Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- Maven

## 🚀 Getting Started

1. Clone the repository

   ```bash
   git clone https://github.com/your-username/springboot-session-security.git
   ```

2. Configure your database in `application.properties`.

3. Run the application.

   ```bash
   mvn spring-boot:run
   ```
